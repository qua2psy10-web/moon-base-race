# 🌕 月面基地レース (moon-base-race)

ライバル国と月面基地の建設を競うターン制シミュレーション。限られた資金・資材・人材で、人類が暮らせる基地を36か月で作り上げよう。

## 起動
```bash
pnpm install
pnpm dev     # 開発サーバ
pnpm test    # ユニットテスト (vitest)
pnpm build
```
サーバ不要。進行は localStorage に自動保存。

## ルール概要
- 36ターン（1ターン＝1か月）。毎ターン2回まで行動（建設 or 研究投資）→「ターン終了」。
- ターン終了後：CPUライバル国が行動 → ランダムイベント（35%）→ 月次収入。
- 基本収入：資金+40 / 資材+5 / 人材+1。開始資源：資金120 / 資材60 / 人材6。
- 電力がマイナスだと施設の生産は半減。技術Lvごとに資金収入+10%。

| 施設 | コスト(資金/資材/人材) | 電力 | 効果 | スコア |
|---|---|---|---|---|
| 🏠 居住区 | 40/30/2 | -2 | 人口上限+5 | 10 |
| ⚡ 発電所 | 30/20/1 | +6 | 電力供給 | 5 |
| ⛏️ 採掘場 | 25/10/2 | -1 | 資材+8/月 | 5 |
| 🔬 研究所 | 50/25/3 | -2 | 技術+4/月 | 8 |
| 🚀 ロケット発射場 | 60/40/3 | -1 | 人材+2・移住+2人・資金+10/月 | 12 |

研究投資：資金30・人材1 → 技術+6pt（20ptで1レベル）。

イベント：太陽フレア／追加予算／建設事故／氷の鉱脈発見／研究者志願。

**最終スコア＝施設スコア合計＋人口×3＋技術Lv×15**。高い方が勝ち。

## MVPの範囲
1人用（CPUライバル1国）、6×6グリッド、シンプルUI。ゲームロジックは `src/game/`（純TS）に分離。
